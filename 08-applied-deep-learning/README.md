# Домашнее задание 8. Глубокое обучение на практике

Решение: [`homework.ipynb`](homework.ipynb)

## Цели задания

- Освоить построение FAISS-индекса и семантический поиск по медицинским текстам с оценкой качества (Recall@k).
- Реализовать полный RAG-пайплайн с двухэтапным ранжированием (bi-encoder + cross-encoder) и генерацией ответа.
- Построить пайплайн прогнозирования временных рядов на основе TimeSeriesTransformer (HuggingFace + GluonTS).
- Проанализировать неопределенность вероятностных прогнозов и сравнить метрики MASE и sMAPE.
- Реализовать метрику pass@k для оценки автоформализации и сравнить стратегии поиска доказательств (greedy vs beam search).
- Интерпретировать результаты в предметном контексте (медицина, финансы, климат, математика).

## Условия

Домашнее задание состоит из 5 задач, каждая по 2 балла. Итого — 10 баллов.
