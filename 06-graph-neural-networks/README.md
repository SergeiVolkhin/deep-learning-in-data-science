# Домашнее задание 6. Графовые нейронные сети

Решение: [`homework.ipynb`](homework.ipynb)

## Цели задания

- Понять, как формулировать прикладную задачу в виде графовой модели с узлами, ребрами и признаками.
- Освоить базовую реализацию GCN-слоя и message passing в матричной форме.
- Научиться обучать и отлаживать простую GCN для классификации узлов на синтетических данных.
- Проанализировать отличия GraphSAGE от GCN и влияние разных типов агрегации соседей.
- Сравнить узловые и графовые постановки через добавление pooling-уровня и graph-level классификатора.
- Интерпретировать полученные эмбеддинги узлов и графов и сделать практические выводы по выбору архитектуры.
