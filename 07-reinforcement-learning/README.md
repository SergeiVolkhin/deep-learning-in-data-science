# Домашнее задание 7. Обучение с подкреплением

Решение: [`homework.ipynb`](homework.ipynb)

## Цели задания

- Понять, как задается среда обучения с подкреплением через состояния, действия, переходы и награды.
- Освоить вычисление дисконтированной доходности и функции ценности для фиксированной стратегии.
- Научиться сравнивать точные методы динамического программирования с выборочными методами Monte Carlo и TD.
- Проанализировать различие между on-policy и off-policy управлением на примере SARSA и Q-learning.
- Сравнить влияние параметров исследования на траектории и устойчивость обучения.
- Интерпретировать результаты экспериментов через свойства среды и алгоритмов.
